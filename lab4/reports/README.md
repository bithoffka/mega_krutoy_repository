# Отчёт о лабораторной работе №4 по дисциплине "Введение в программирование и алгоритмы"

### *Ход работы:*

Вариант №2, базовый, средний и повышенный уровни сложности.
| Уровень сложности | Задача |
|--|--|
| Базовый  | По номеру месяца (1-12) вывести название месяца |
| Средний | По номеру месяца (1-12) вывести время года (группировка: зима, весна, лето, осень) |
| Повышенный | Геометрический калькулятор: меню фигур (1-Круг, 2-Квадрат, 3-Прямоугольник, 4-Треугольник). Для каждой фигуры — подменю (площадь, периметр) |

### *Повышенный уровень сложности:*
![Фото кода в IDE](https://github.com/bithoffka/mega_krutoy_repository/blob/main/lab4/media/hard_var2_photo.png?raw=true)

> Краткое описание кода:

Подключил заголовочные файлы `<iostream>`, `<iomanip>`, `<string>`, `<sstream>`, `<array>` и `<cmath>` для работы с вводом, выводом, форматированием чисел, строками, строковыми потоками, массивами и математическими функциями. Добавил условную компиляцию для Windows и настроил UTF-8 в консоли с помощью `<Windows.h>`. Создал шаблонную функцию `get_number()`, которая позволяет получать значения разных числовых типов и проверять корректность ввода с помощью `std::getline()`, `std::stringstream` и нескольких условий. На её основе создал функции `get_short_in_range()` и `get_positive_double()` для получения чисел с нужными ограничениями. Также реализовал функцию `get_triangle_sides()`, которая запрашивает три стороны и проверяет возможность существования треугольника (невырожденность), возвращая массив `std::array`. В `main()` вывел меню, запросил у пользователя выбор фигуры и типа операции. С помощью вложенных конструкций `switch-case` организовал запрос соответствующих параметров (радиуса или сторон) и вычисление площади или периметра для выбранной фигуры (круга, квадрата, прямоугольника или треугольника). Затем вывел результат, использовав `std::fixed` и `std::setprecision(6)`. В конце использовал `std::cin.get()`, чтобы программа не закрывалась сразу после вывода результата.
