# Отчёт о лабораторной работе №3 по дисциплине "Введение в программирование и алгоритмы"

### *Ход работы:*

Вариант №2, базовый, средний и повышенный уровни сложности.
| Уровень сложности | Задача |
|--|--|
| Базовый  | Запросить два числа и вывести большее из них |
| Средний | Запросить номер месяца (1-12). Вывести название месяца и количество дней в нём (без учёта високосности) |
| Повышенный | Определитель возраста: запросить год рождения и текущий год. Вывести возраст и категорию: ребёнок (0-12), подросток (13-17), взрослый (18-64), пожилой (65+) |

### *Базовый уровень сложности:*
![Фото кода в IDE](https://github.com/bithoffka/mega_krutoy_repository/blob/main/lab3/media/base_var2_photo.png?raw=true)
> Краткое описание кода:

Подключил заголовочные файлы `<iostream>`, `<iomanip>`, `<string>` и `<sstream>` для работы с вводом, выводом, форматированием чисел, строками и строковыми потоками. Добавил условную компиляцию для Windows и настроил UTF-8 в консоли с помощью `<Windows.h>`. Создал функцию `get_double()`, которая получает от пользователя число и проверяет корректность ввода с помощью `std::getline()`, `std::stringstream` и нескольких условий. В `main()` получил первое и второе число, сравнил их с помощью конструкции `if`. Затем вывел результат, использовав `std::setprecision(10)`. В конце использовал `std::cin.get()`, чтобы программа не закрывалась сразу после вывода результата.
