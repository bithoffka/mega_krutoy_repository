| Уровень сложности | Задача |
|--|--|
| Базовый  | Перевод минут в секунды |
| Средний | Запросить скорость (км/ч) и время (ч), вывести расстояние

### *Базовый уровень сложности:*
![Фото кода в IDE](https://github.com/bithoffka/mega_krutoy_repository/blob/main/lab1/media/base_var2_photo.png?raw=true)
> Краткое описание кода:

Подключил заголовочные файлы `<iostream>`, `<sstream>` и `<string>` для работы с вводом, выводом, строками и строковыми потоками. Добавил условную компиляцию для Windows и настроил UTF-8 в консоли с помощью `<Windows.h>`. Создал функцию `get_non_negative_double()`, которая получает от пользователя число и проверяет корректность ввода с помощью `std::getline()`, `std::stringstream` и различных условий. При ошибке выводится сообщение через `std::cerr`, после чего пользователь может повторить ввод благодаря циклу `while`. В `main()` получил количество минут и сохранил его в переменную типа `double`, затем перевёл минуты в секунды и вывел результат. В конце использовал `std::cin.get()`, чтобы программа не закрывалась сразу после вывода результата.

### *Повышенный уровень сложности:*
![Фото кода в IDE](https://github.com/bithoffka/mega_krutoy_repository/blob/main/lab1/media/hard_var2_photo.png?raw=true)

> Краткое описание кода:

Подключил заголовочные файлы `<iostream>`, `<sstream>` и `<string>` для работы с вводом, выводом, строками и строковыми потоками. Добавил условную компиляцию для Windows и настроил UTF-8 в консоли с помощью `<Windows.h>`. Создал шаблонную функцию `get_number()`, которая позволяет получать значения разных числовых типов и проверять корректность ввода. Создал отдельные функции для проверки выбора пункта меню и получения неотрицательного числа типа `double`. В `main()` вывел меню выбора единицы измерения и с помощью `switch-case` реализовал перевод километров, метров или сантиметров в миллиметры. Для каждой единицы измерения введённое значение умножается на соответствующий коэффициент, после чего результат выводится на экран. В конце использовал `std::cin.get()`, чтобы программа не закрывалась сразу после вывода результата.
