# Отчёт о лабораторной работе №5 по дисциплине "Введение в программирование и алгоритмы"

### *Ход работы:*

Вариант №2, базовый, средний и повышенный уровни сложности.
| Уровень сложности | Задача |
|--|--|
| Базовый  | Табуляция функции f(x) = x^2 - 2x + 1 на интервале [a, b] с шагом h |
| Средний | Табуляция функции cos(x), анализ минимального и максимального значений |
| Повышенный | Табуляция эталонного cos(x) и приближения через ряд Тейлора, анализ погрешности |

### *Базовый уровень сложности:*

> Краткое описание кода:

Подключил заголовочные файлы `<iostream>`, `<iomanip>`, `<string>`, `<sstream>`, `<cmath>` и `<algorithm>` для работы с вводом/выводом, форматированием, строковыми потоками и математическими вычислениями. Добавил условную компиляцию для Windows и настроил UTF-8 в консоли с помощью `<Windows.h>`. Создал функцию `get_double()`, которая безопасно получает число от пользователя, проверяя корректность ввода с помощью `std::getline()`, `std::stringstream` и нескольких условий. Добавил структуру `TabulationValues` и функцию `get_function_tabulation_values()`, где через циклы `while` настроил получение границ и шага табуляции с проверкой логических условий. Реализовал функцию `tabulated_function()` для вычисления заданного уравнения. В `main()` настроил динамическое вычисление точности (с учетом возведения аргумента в квадрат) и ширины колонок, вывел отформатированную шапку таблицы с помощью манипуляторов `std::setw` и `std::left`, а затем протабулировал функцию в цикле `for`, используя константу `EPSILON` для защиты от погрешности дробных чисел. В конце использовал `std::cin.get()`, чтобы программа не закрывалась сразу после вывода результата.

> Краткое описание кода:

Подключил заголовочные файлы `<iostream>`, `<iomanip>`, `<string>`, `<sstream>`, `<array>`, `<cmath>` и `<algorithm>` для работы с вводом/выводом, форматированием, строковыми потоками и математическими вычислениями. Добавил условную компиляцию для Windows и настроил UTF-8 в консоли с помощью `<Windows.h>`. Создал шаблонную функцию `get_number()`, которая безопасно получает число от пользователя, проверяя корректность ввода с помощью `std::getline()`, `std::stringstream` и нескольких условий. Добавил структуру `TabulationValues` и функции `get_function_tabulation_values()` и `get_number_of_terms()`, где через циклы `while` настроил получение границ, шага табуляции и количество членов ряда Тейлора, которые необходимо вычислить с проверкой логических условий. Написал функцию `taylor_cos()`, в которой нормализовал аргумент через `std::fmod()` для предотвращения переполнения на больших числах, а затем вычислил ряд Тейлора рекуррентно в цикле `for`. В `main()` настроил динамическое вычисление точности (с учетом возведения аргумента в квадрат) и ширины колонок, вывел отформатированную шапку таблицы с помощью манипуляторов `std::setw` и `std::left`, а затем протабулировал функцию в цикле `for`, используя константу `EPSILON` для защиты от погрешности дробных чисел, вывел эталонный косинус, косинус по Тейлору и их абсолютную разность. В конце использовал `std::cin.get()`, чтобы программа не закрывалась сразу после вывода результата.
