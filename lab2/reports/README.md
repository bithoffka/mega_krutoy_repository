# Отчёт о лабораторной работе №2 по дисциплине "Введение в программирование и алгоритмы"

### *Ход работы:*

Вариант №2, базовый, средний и повышенный уровни сложности.
| Уровень сложности | Задача |
|--|--|
| Базовый  | Вычисление площади круга |
| Средний | Вычисление площади круга и длины окружности
| Повышенный | Вычисление площади треугольника по формуле Герона

### *Базовый уровень сложности:*
![Фото кода в IDE](https://github.com/bithoffka/mega_krutoy_repository/blob/main/lab2/media/base_var2_photo.png?raw=true)
> Краткое описание кода:

Подключил заголовочные файлы `<iostream>`, `<iomanip>`, `<string>`, `<sstream>` и `<cmath>` для работы с вводом, выводом, форматированием чисел, строками, строковыми потоками и математическими функциями. Добавил условную компиляцию для Windows и настроил UTF-8 в консоли с помощью `<Windows.h>`. Создал функцию `get_positive_double()`, которая получает от пользователя положительное число и проверяет корректность ввода с помощью `std::getline()`, `std::stringstream` и нескольких условий. Также создал функцию `get_truncated()`, которая выполняет усечение числа до указанного количества знаков после запятой с использованием явного приведения типов. В `main()` объявил константу `pi`, получил радиус круга, вычислил его площадь. Затем вывел результат в типе `double`, продемонстрировал потерю точности при приведении к типу `float`, а также показал разницу между округлением и усечением числа до 6 знаков после запятой. В конце использовал `std::cin.get()`, чтобы программа не закрывалась сразу после вывода результата.
